Food delivery operations dashboard

Delivery performance across couriers, zones and time of day — built to show where orders lose time and which of those delays are worth fixing. Filter and drill into any view below.

Interactive Use the page tabs along the bottom of the report to move between views.

This report is built for a wider screen. Open it directly for the full interactive version.

Open the dashboard

What it answers

  • Which delivery zones miss their promised window most often
  • How courier performance shifts across the dinner peak
  • Where order-to-doorstep time is actually being lost

How it's built

  • Power BI Desktop — import model, star schema
  • Measures in DAX; transformations in Power Query
  • Source data and model documented in the repo
